n8n Pipeline — Automatisierte Prompt-Generierung
Self-Hosted n8n Workflow, der eingehende Rohdaten via Webhook erfasst, KI-System-Prompts dynamisch baut, validiert und als strukturierte JSON-Payload bereitstellt.
↓

Workflow Architecture

TRIGGER (Webhook Node) → Nimmt eintreffende Anwendungsfälle / Formular-Inputs entgegen DATA TRANSFORMATION (Edit Fields / Code Node) → Bereinigt Strings, extrahiert Tonalität, Branche & Verbote → Generiert dynamische Kontext-Variablen AI EXECUTION (OpenAI / Claude Node in n8n) → Nutzt maßgeschneiderten Meta-Prompt für System-Prompt-Erstellung → Injiziert Guardrails (DSGVO, AGG, Verbotene Phrasen) VALIDATION & ROUTING (Switch Node) → Prüt KI-Output auf Format-Einhaltung & JSON-Syntax → Bei Erfolg: Payload-Ausgabe an Zielsystem / Netlify App → Bei Fehler: Fallback-Schleife mit Error-Notification

Warum das besonders ist

  • End-to-End Automatisierung in n8n ohne manuelles Copypasten
  • Umgang mit komplexen Data-Payloads & JSON-Strukturen
  • Eingebautes Fallback-Routing bei unerwartetem KI-Output
  • Skalierbar: Kann als Backend für Formulare, Chatbots oder Tools dienen

Der Orchestrator-Prompt (im n8n LLM Node)

### ROLLE Du bist der Orchestrator für Krankenkasse XY innerhalb der n8n-Workflow-Pipeline. Du analysierst die per JSON übergebene Kundenanfrage und bestimmst das exakte Routing. ### ENTSCHEIDUNGSREGELN — KI-Agents - Erstattung, Rechnung, Krankengeld, Zahlung → Erstattungs-Agent (Signal: RESTART_PAYMENT) - Leistungen, Kostenübernahme, Behandlung, Reha → Leistungs-Agent (Signal: SERVICE_INFO) - Adressänderung, Namensänderung → Adress-Agent (Signal: ADDRESS_UPDATE) ### ENTSCHEIDUNGSREGELN — MENSCH / ESKALATION - Emotionale Signale (Angst, Verzweiflung) → Mensch (Signal: HUMAN_ESCALATION) - Beschwerden, Kündigung → Mensch - Krisenbegriffe ("keine Kraft mehr", "am Ende") → Signal: CRISIS_PRIORITY ### DATENSCHUTZ & SONDERREGELN - Externe E-Mail → Signal: VERIFY_PORTAL - Minderjährigen-Anfrage mit gemeinsamem Sorgerecht → Signal: CUSTODY_CHECK ### OUTPUT FORMAT { "routing_target": "[SIGNAL]", "priority": "HIGH/MEDIUM/LOW", "reason": "Kurze Begründung" }

Warum das besonders ist

  • Verbindet komplexe System-Prompts direkt mit n8n Switch- & IF-Nodes
  • Strikte Ausgabe von JSON zur nahtlosen Weiterverarbeitung im nächsten Node
  • Praxisnahe Sonderregeln (Sorgerecht, DSGVO, Krisensignale) direkt im Routing verankert

Der Prompt

Schreibe einen passenden Betreff. Antworte auf einen verärgerten Kunden der zu lange Bearbeitungszeiten hat. ### ROLLE Empathischer Kundenservice-Mitarbeiter einer Krankenkasse. ### REGELN - Freundlich, menschlich, nicht zu steif - Biete Rückruf oder Filialtermin an - Entschuldige dich und nenne eine konkrete Lösung - Wähle passenden Tagesgruß - Nenne Kontaktmöglichkeiten - Antwort: ~200 Wörter - Sprache automatisch erkennen (Deutsch / Englisch / Türkisch) ### KUNDENTYPEN — Ton automatisch anpassen - Sehr wütend ("Ich kündige / verklage Sie") → deeskalierend, besonders empathisch - Unzufrieden ("Wann wird das bearbeitet?") → lösungsorientiert, ruhig - Nachfragend ("Wie funktioniert das?") → erklärend, freundlich ### VERBOTE - Keine medizinischen Aussagen - Keine Kostenübernahme versprechen - Keine rechtlichen Zusicherungen - Keine persönlichen Daten weitergeben [KUNDENMAIL]

Warum so gebaut

  • Drei Kundentypen mit Beispielsätzen — KI passt den Ton automatisch an
  • Verbote schützen vor rechtlichen Risiken im Gesundheitsbereich
  • Mehrsprachigkeit ohne manuelles Eingreifen

Praxiserkenntnisse & Prinzipien

Von einzelnen Prompts zu robusten n8n-Pipelines

Workflow-Orchestrierung Ein Prompt ist nur so gut wie das System drumherum. n8n verbindet KI-Power mit echten Business-APIs.
Struktur schlägt Länge Klar gegliederte System-Prompts mit XML-Tags oder Markdown führen zu verlässlichen, reproduzierbaren Outputs.
Verbote & Guardrails Was die KI *nicht* tun darf, schützt Unternehmen vor Haftung, Halluzinationen und Prompt-Injections.
JSON als Lingua Franca Gezielte Output-Formatierung in JSON erlaubt die problemlose Weiterverarbeitung in n8n-Nodes & Datenbanken.
Rechtliche Leitplanken DSGVO, AGG und branchenspezifische Vorgaben gehören als unumstößliche Regeln direkt in den System-Prompt.
Iteratives Testing Erst Stresstests mit fehlerhaften oder aggressiven Nutzereingaben machen eine Automatisierung produktionsreif.
Eigene Infrastruktur n8n läuft selbst gehostet auf einem IONOS vServer und bildet die Grundlage für dauerhaft verfügbare Automationen.
Vom Prompt zur Anwendung Gute KI-Logik wird erst dann interessant, wenn sie in Frontends, Workflows und reale Prozesse eingebettet wird.
